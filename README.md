# PISA 2025 — очищені дані (математика + соцекономічний статус)

Джерело: OECD PISA 2025, файл учнів `CY09_MS_STU_PUF.sav`.

- `PISA2025_math_SES_clean.sav` — SPSS, з назвами змінних і підписами значень
- `PISA2025_math_SES_clean.csv.gz` — той самий набір у CSV (стиснений gzip)

747 068 учнів, 89 країн, 21 колонка.

| Колонка | Опис |
|---|---|
| CNTSTUID | ID учня (дублікатів немає) |
| CNT | Код країни |
| PV1MATH … PV10MATH | 10 правдоподібних значень балу з математики |
| W_FSTUWT | Фінальна вага учня |
| HISCED | Найвищий рівень освіти серед батьків (ISCED, 1–9) |
| P1ISCED, P2ISCED | Освіта батька/опікуна 1 і 2 (у PISA 2025 замість MISCED/FISCED) |
| PAREDINT | Освіта батьків у роках навчання |
| ST255Q01JA | Кількість книжок удома (1–7) |
| HOMEPOS | Індекс домашнього майна (WLE); WEALTH у PISA 2025 немає, HOMEPOS включає книжки |
| ESCS | Індекс економічного, соціального та культурного статусу |

## Очищення
- Коди пропусків (95–99, 9997) замінено на порожні значення.
- Видалено 8 653 учнів без балів з математики.
- Учнів із неповними даними про родину залишено.
